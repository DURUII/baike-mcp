## toy-baike-mcp

A Toy MCP server for Baidu Baike via FastMCP.

### Tools

- Tool 1: `baike_markdown(name: str)` → general query, returns markdown content
- Tool 2: `baike_episode_summary(name: str)` → TV/film episodes, normalized `episode_summary`

### Example
Call `baike_episode_summary` with `"甄嬛传"` and expect `count = 76`.

### Availability
Also available on the Coze Plugin Store (search: "电视通").
